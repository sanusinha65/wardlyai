# WardlyAI Engineering Exercise - Requirements

## Exercise
Build a working voice (or chat-based) agent that conducts a pre-visit clinical intake with a simulated patient and generates a structured clinical brief (CC, HPI, ROS) at the end.

## Implementation Options
- **Voice (inbound/outbound call)**: Bonus points for real call implementation
- **CLI or web-based conversation**: Acceptable if voice is too time-consuming

## Time Box
4-5 hours

## Submission
- GitHub repository with code
- 5-minute Loom video showing end-to-end interaction
- Timeline: Submit within 2-3 days

## Evaluation Criteria
**Primary Focus:**
- How you approach the problem
- Conversation flow design
- Quality of structured output for clinicians

**Secondary (less focus on):**
- Visual polish
- Perfect UI aesthetics

## Success Metrics
1. Agent can conduct a coherent pre-visit intake conversation
2. Output is well-structured (CC, HPI, ROS)
3. Clinician can quickly understand the patient's situation from the brief
